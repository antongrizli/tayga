# Security policy

Report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/antongrizli/tayga/security/advisories/new).
If that channel is unavailable, open an issue requesting a private contact without
including exploit details, sensitive packet captures or credentials.

Include the commit or version, build flags, operating system, configuration with
secrets removed, a minimal reproducer and the observed impact. Packet parsing,
mapping reload, offload metadata and privilege transitions are security-sensitive.

Fixes are developed against the current main branch. Older releases have no
promised backport or support window. Acknowledgment and release dates depend on
maintainer availability; do not assume a fixed response SLA.
