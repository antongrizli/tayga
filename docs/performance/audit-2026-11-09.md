# A/B приёмка аудита: 2026-11-09

35 запусков / 70 направленных измерений: 5 повторов каждой ячейки. Все
захваты валидны, workload acceptance PASS, TUN/worker drops и errors = 0.
Реальная worker affinity проверена по CPU masks потоков. Установленные
guest binary/startup/status восстановлены, hashes до/после совпали.

Baseline: `7acb2fe71f0574fc4f258fe4a5ebb77d160132d1`, kernel/off.
Candidate: `a61fa20011465d5679654eaf84c90fbca3ec001c` + локальные изменения.
Общий текущий startup/harness, WITH_URING=1 build, sync packet I/O, TCP offload,
3 workers, 8 клиентов × 1 поток, фиксированные source ports, 2 s warmup / 5 s
measurement, upload/download. Порядок ячеек развёрнут в чётных повторах.
ARM64 Linux VM, 8 vCPU; это не измерение физического NIC и не обещание
производительности на других устройствах.

Метрика: сумма sender retransmits / (receiver application bytes / 1e9).
Нельзя подменять её retransmits на sender GB или полным lifetime TcpRetransSegs.
Результаты каждой пары и raw iperf JSON сохранены.

## Уточнение default kernel

Выполнена дополнительная узкая серия: 5 пар baseline/candidate, тот же
kernel/off, 5 s warmup / 20 s measurement. Все 10 запусков / 20 направленных
измерений валидны, 0 TUN/worker drops/errors, восстановление файлов подтверждено.
Короткая матрица выше сохранена, не заменена новым результатом.

| Variant | Direction | Median Gbit/s | Median retrans/received GB | Retrans ≤ +10% | Throughput ≥ −2% |

| baseline | upload | 96.19 | 8.89 | PASS | PASS |

| candidate | download | 95.43 | 10.87 | FAIL | PASS |

На длинном окне default kernel/off проходит throughput в обоих направлениях и
upload retransmits/GB, но download retransmits/GB не проходит: 10.87 против
6.82 (+59.4%). Разброс baseline download 1.44–23.88, candidate 2.48–13.52;
этот результат не устанавливает причинную связь с конкретным изменением кода.
Нужны отдельные профили/pcap и контроль kernel queue distribution для объяснения
превышения. Менять packet path или production default ради этого бенчмарка
без установленной причины нельзя.

**Итог: B1 / performance acceptance не закрыт и блокирует заявление о готовности
выпуска.** Корректность, отсутствие TUN/worker drops/errors и прохождение
санитайзеров не заменяют этот gate. Groups/flows/dispatch/io_uring остаются
experimental opt-in; универсальный выигрыш не заявлен.
